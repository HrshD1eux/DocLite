# DocLite Screenshots

Drop any app screenshots (`.png`, `.jpg`, `.jpeg`, `.webp`) into this folder or `docs/screenshots/`.

### How Auto-Display Works:
The DocLite GitHub Pages landing page automatically queries the GitHub API (`/repos/HrshD1eux/DocLite/contents/docs/screenshots` and `/repos/HrshD1eux/DocLite/contents/screenshots`) to detect all images in this folder on page load. 

Any image file you commit and push to this directory will immediately appear in the interactive screenshot showcase and lightbox on the live website without editing a single line of HTML!
