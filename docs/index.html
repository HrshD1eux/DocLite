Frequently Asked Questions

Straightforward answers about DocLite's security, features, and permissions.

Is DocLite really 100% offline? ▼
Yes. DocLite does not require network access for any of its document rendering or analysis features. All parsing engines (Apache POI, PDFBox, Android native PdfRenderer) execute directly within the app process on your device.
How does the Bank Statement Analyzer handle my private finances? ▼
Your statement data never leaves your device. The parser runs strictly in local memory to identify debit/credit columns and cleanse UPI/NEFT/ATM strings. As soon as you navigate away, the in-memory parsing buffer is cleared.
Can DocLite open password-protected PDFs and Excel files? ▼
Yes. When a password-protected PDF or encrypted Excel sheet is opened, DocLite prompts you for the password and decrypts the stream locally in memory using native PDFBox and Apache POI.
What permissions does DocLite require? ▼
DocLite adheres strictly to Android Scoped Storage standards. It uses the standard Android Storage Access Framework (SAF) system file picker and read-only media permissions. It does not request invasive permissions or sideloading capabilities.
